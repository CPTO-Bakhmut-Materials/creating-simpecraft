> **Що ми побудуємо:** невелику гру в стилі Minecraft для ПК. Ми літатимемо над островом з блоків, ламатимемо їх і ставитимемо нові. Світ зберігається у відкритому форматі `.vox` і редагується безкоштовним 3D-редактором.

## Для кого цей курс

Курс розроблено для здобувачів освіти за професією **4113 «Оператор з обробки інформації та програмного забезпечення»** (стандарт професійної освіти ДОС 4113 J.62.00-63.10-2022). Попередній досвід програмування бажаний, але не обов'язковий: необхідний мінімум мови Lua пояснюється в уроці 1.

Курс не вчить «робити ігри» як таких. Гра тут — **наочний спосіб** розібратися з темами, які потрібні оператору з обробки інформації:

| Компетентність стандарту | Де в курсі |
|---|---|
| **ПК 6.** Технологічні операції з обробки тривимірних зображень: сцена, об'єкти, примітиви, камера, матеріали й текстури, рендеринг | уроки 2–7, 9 |
| **ПК 4.** Обробка растрових зображень: формати, колірні моделі, масштабування, фільтри | уроки 5, 8 |
| **ПК 8.** Робота з даними: структури даних, формати файлів, перевірка коректності | уроки 6, 8, 9 |
| **ПК (ОС та ПЗ).** Встановлення, налаштування та підтримка прикладного ПЗ, периферійні пристрої | уроки 0, 1, 4, 10, 11 |
| **КК.2 Математична** | вектори, матриці, тригонометрія, системи числення: уроки 1–9 |
| **КК.1 Комунікативна** (англійська термінологія) | у кожному уроці; [словник термінів](../GLOSSARY.md) |
| **КК.3 Особистісна, навчальна** | самоперевірка в кінці кожного уроку, урок 11 |

## Технічне завдання

Курс відтворює еталонний проєкт **love-mcraft**. Ось його вимоги:

1. Простий клон Minecraft; точна відповідність оригіналу не потрібна, наближення допустимі.
2. Сторонні бібліотеки — лише якщо власна реалізація була б дуже великою. (У курсі їх не знадобилося.)
3. Невеликий **готовий** світ для перевірки, без генерації світу кодом.
4. Вільний рух камери, можливість **ставити землю** й **ламати будь-який блок**. Зміни не зберігаються: файл світу лише читається.
5. **Відкритий формат світу**, який можна редагувати й переглядати сторонніми програмами, наприклад `.vox`.
6. Жодних меню; з інтерфейсу лише приціл.
7. Кілька типів блоків (камінь, земля, трава) з **відкритими текстурами**.
8. Без зіткнень (камера пролітає крізь блоки).

> **Відмінність від еталону.** love-mcraft працює також у браузері та на телефонах із сенсорним керуванням. Цей курс зосереджено **лише на ПК** з мишею та клавіатурою. Різницю докладно розібрано в уроці 10.

## Підготовка робочого місця

### 1. LÖVE 11.5

[LÖVE](https://love2d.org) — безкоштовний рушій з відкритим кодом для ігор мовою Lua.

| ОС | Встановлення |
|---|---|
| Windows | інсталятор `love-11.5-win64.exe` з [love2d.org](https://love2d.org) |
| Ubuntu / Debian | `sudo add-apt-repository ppa:bartbes/love-stable && sudo apt install love` |
| Arch Linux | `sudo pacman -S love` |
| macOS | архів `love-11.5-macos.zip` з [love2d.org](https://love2d.org), перетягнути в «Програми» |

Перевірка:

```sh
love --version
# LOVE 11.5 (Mysterious Mysteries)
```

> **Windows:** якщо команда `love` не знаходиться, додайте `C:\Program Files\LOVE` до змінної середовища `PATH` або запускайте гру, перетягнувши теку `code` на ярлик `love.exe`.

### 2. Редактор коду

Підійде будь-який редактор. Рекомендуємо **Visual Studio Code** з розширенням **Lua** (автор *sumneko*): воно підсвічує помилки й підказує назви функцій LÖVE.

### 3. Goxel (для уроку 8)

[Goxel](https://goxel.xyz) — безкоштовний редактор вокселів з відкритим кодом (Windows, Linux, macOS). Ним ми редагуватимемо світ.

### 4. LuaJIT або Lua (для уроку 11)

Щоб запускати тести без гри, потрібен інтерпретатор Lua: `luajit` (рекомендовано) або `lua`. На Linux він є в менеджері пакетів (`sudo apt install luajit`), для Windows його можна завантажити з [luajit.org](https://luajit.org) або [luabinaries](https://luabinaries.sourceforge.net).

## Як працювати з уроками

Кожен урок — окрема тека:

```
05-textures/
├── README.md     ← текст уроку
├── images/       ← скриншоти, анімації, схеми
└── code/         ← повний робочий код НАПРИКІНЦІ уроку
```

Запуск коду будь-якого уроку:

```sh
cd 05-textures/code
love .
```

Рекомендований порядок роботи:

1. Прочитайте урок і **запустіть** код з теки `code`, щоб побачити результат.
2. Скопіюйте `code` **попереднього** уроку в окрему робочу теку й **самостійно** внесіть зміни, описані в уроці. Звіряйтеся з `code` поточного уроку.
3. **Відтворіть типову помилку** з розділу «⚠️ Типові помилки» й переконайтеся, що бачите те саме, що на скриншоті. Уміння впізнати помилку з вигляду цінніше за вміння її не робити.
4. Дайте відповіді на запитання для самоперевірки.

Кожен урок має однакову будову:

| Розділ | Зміст |
|---|---|
| Результат уроку | що вийде в кінці (з анімацією) |
| Мета уроку | чого навчимося |
| Теорія зі схемами | математика й алгоритми з наочними ілюстраціями |
| Код | розбір ключових фрагментів; повний код у теці `code` |
| ⚠️ Типові помилки | що буде, якщо помилитися, зі скриншотами |
| Підсумок і запитання | короткий конспект і завдання |
